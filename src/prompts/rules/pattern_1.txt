Use the tools in this exact sequence:
1. think
2. zoom_region
3. confirm_read
4. add_footing

Rules:
- think must be first and must return structured observable extraction planning data.
- zoom_region must be used for column mark cells, unclear dimensions, reinforcement spacing, and global notes.
- confirm_read must record exact text from each zoomed region before that region is used as source evidence.
- add_footing must include source_region_ids that support the footing values.
- Do not invent values. If a value is not visible, use null or [].

Footing-specific rules:
- Column IDs must be copied exactly as written in the schedule.
- Keep grouped IDs as one string when they share one footing specification.
- Size uses plan_width and plan_length from the visible B x L or L x W cell.
- For D TO d depth, use the smaller/bottom d value as size.depth.
- Extract reinforcement diameter as T12, T16, etc.
- Convert visible spacing values like 150 to "150 C/C".
- Extract mix and steel grade only if visible in the table or global notes.
- Process every visible footing/column group.
