========================
VERY STRICT RULES
========================

1. COLUMN LOCK:
For each footing column (F1, F2, F3, ... CFT-1):
Only extract values vertically under that exact column.
Never shift left or right.

2. IGNORE COMPLETELY:
- Row labeled: B' x L' (PCC)
Never use any values from this row.

3. SIZE EXTRACTION:

From row labeled exactly:
B x L

- First value = width
- Second value = length

From row labeled exactly:
D

- depth = value in that column

Do NOT use values from:
- PCC row
- t row
- Any other row

If value is unclear or unreadable, return null.
Do NOT guess.
Do NOT approximate.
Do NOT invent.

4. REINFORCEMENT:

Extract from these four rows under the SAME footing column and combine
them into the reinforcement fields of add_footing:

  STEEL // - B (SHORT SIDE) (BOTTOM FACE)  -> short_span_reinf
  STEEL // - L (LONG SIDE) (BOTTOM FACE)   -> long_span_reinf
  STEEL // - B (SHORT SIDE) (TOP FACE)     -> append to short_span_reinf
  STEEL // - L (LONG SIDE) (TOP FACE)      -> append to long_span_reinf

When two SHORT-side cells share a value, pass the value once. When they
differ, pass both, comma-separated, e.g. "12T-100c/c, 16T-150c/c".
Never leave the reinforcement fields empty just because the four cells
visually look identical — pass the value through so it lands in
reinforcement.dia and reinforcement.spacing.

If cell contains:
12T-100 c/c

Extract:
dia = "12T"
spacing = "100 C/C"

Rules:
- Keep dia exactly as written (12T, 16T, 10T etc.)
- Do NOT convert to T12.
- Convert spacing to uppercase format "100 C/C"
- If a cell contains only "-", ignore that single cell (still extract the others).
- Do NOT merge values from other footing columns.
- Do NOT guess missing reinforcement.

5. footing_id:
Use column header exactly (F1, F2, F3, ... CFT-1).

6. column_id = null
7. nos = null
8. mix = null
9. steel_grade = null

If unsure, return null instead of wrong value.
